Privacy policy

mimir Home Calendar. Last updated 30 September 2026.

mimir Home Calendar connects Google Calendar to a Home Assistant server run by one household in its own home. It is operated by Erik Karwatowski for members of that household only. This page explains what Google user data it accesses and what happens to it.

What data it accesses

When a household member signs in with Google and grants permission, the app receives access to their Google Calendar through the scope https://www.googleapis.com/auth/calendar. With that access it:

  • reads the list of their calendars and the events on them, including titles, times, locations and descriptions;
  • creates or changes an event only when a household member asks Home Assistant to do so.

It does not access email, contacts, files, or any other Google data.

How the data is used

Calendar data is used only to show the household's upcoming events in Home Assistant, and to answer household members' own questions about their schedule. Those answers are produced by software that runs on the same home server, including language models that run locally. Calendar data is not sent to any outside AI service.

Where the data is kept

All of it stays on the household's own server:

  • The access token Google issues is stored in Home Assistant's configuration on that server.
  • Recent event information is kept in Home Assistant's history, which by default is removed after 10 days.
  • Encrypted backups of the server's configuration, which include the stored token, are kept on a disk in the same server and on one other computer owned by the family. They are encrypted before they leave the server.

Sharing

Google user data is not sold, rented, or shared with anyone outside the household. It is not used for advertising, and it is not used to train AI models. The app uses no analytics or tracking, and these pages set no cookies.

The app's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and deleting data

You can remove the app's access at any time at myaccount.google.com/permissions. Once access is removed, the stored token no longer works. To have the stored token and any calendar data deleted from the server and its backups, email the address below.
